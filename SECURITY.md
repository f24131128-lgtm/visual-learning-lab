# Security

Do not post credentials, private source material or an exploit containing secrets
in a public issue. For a suspected vulnerability, use GitHub private vulnerability
reporting if enabled; otherwise contact the repository owner privately before
sharing exploit details. Private reporting availability has not been verified.

Never expose the localhost personal launcher through a public tunnel. It enables
private AI actions without public-user metering. Public AI must retain verified
identity, persistent admission ledger and the release gate.

API keys belong in process environment or ignored Streamlit secrets. The browser
and model output must not receive them. Source excerpts are untrusted data.
Root software licensing and individual material licenses are separate concerns.
