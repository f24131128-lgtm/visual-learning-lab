# Visual Learning Lab — Competition Edition

把教材變成可以探索的理解空間。

最短的產品證明是：訪客打開已準備好的教材，操作一個數學模型，看相關數值
和圖形一起變化，再回到沒有被探索值改寫的原始 PDF。

[正式 app](https://visual-learning-lab-kdemsgmw3swykt5zpqbkc5.streamlit.app/) ·
[展示腳本](DEMO_SCRIPT.md) · [實測與限制](../DAY30_EVIDENCE.md) ·
[開發決策](DEVELOPMENT_DECISIONS.md) · [公平比較協定](FAIR_COMPARISON.md)

兩份封裝素材：簡諧運動以 A／T／φ 滑桿對照固定來源曲線；拋體運動以既有
向量反解與 World reducer 提交初速度／角度。第二份明確是 Day26 封存衍生版，
不是宣稱歷史回應完全沒改。載入與本機操作均不需要新的付費生成。

技術特色是有界宣告、共同語意 identity、來源支持、正式提交狀態與失敗保全。
UI 沒有執行模型生成的程式碼；也沒有為示例另寫一套物理。Learn／Source／
Explore／Practice 共用當前教材，導覽與測驗保持本機。

競賽說法的邊界：工程可用性、來源對應正確、真人理解／學習效果是三件不同
的事。Day27 的語意結果和 Day28 的 AI 模擬都保留原分母與限制。兩位學生的
非正式正向印象不是正式研究。既有安全、授權與 paid-public 獨立驗收仍適用。
