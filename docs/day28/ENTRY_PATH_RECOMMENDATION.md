# 準備示例／自己的教材：文案候選，未改產品

先完成並封存全部人類 baseline，再依據重複摩擦決定是否給正式首頁加一個小入口。當前正式首頁未改；研究 wrapper 的附加按鈕是 disclosed accommodation。

| 路徑 | 候選文案 | 實際行為與诚實邊界 |
|---|---|---|
| A | 「試用準備好的示例」／Try a prepared example；「預先生成並檢查，可立即開始；不是這次即時分析。」 | 本機固定法律允許素材；明確載入準備內容，不做假進度／假 AI 生成。不得當成 live success。 |
| B | 「使用自己的教材」／Use your own material；「上傳 PDF 或貼上文字，由 AI 分析，通常需要等待；部分材料可能只提供較簡單的表示或無法建立互動。」 | 現有正式 PDF／text explicit analysis；保留安全拒绝／fallback，不保證生成時延或成功率。 |

只記錄建议，不加入 onboarding wizard、renderer、Candidate C 或正式 demo 狀態。只有人類數據支持並獲後續授權才評估至多兩項小修。Source 原文件不會隨任何路徑的探索變量變動。
