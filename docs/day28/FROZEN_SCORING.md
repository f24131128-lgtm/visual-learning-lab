明確例外：單純把未指定單位寫錯，或數值筆誤但清楚正確說出翻倍／不變，可按概念得分並記錯誤；若因此表達不同模型關係，按上表。矛盾回答按其最後明確主張評，不能挑出正確片段；不能追問暗示改答。超時按已交內容評分並記超時，不自動給 0 或模擬完成。

退出且無可評回答：score=null，不是假造 0，保留退出行與 condition；報告 denominators。完成但明確「不知道」為 score=0。應用故障無回答同樣 null 與 app_failure。只有 human scorer 的明確判斷才能填 score，理由必須保留。
